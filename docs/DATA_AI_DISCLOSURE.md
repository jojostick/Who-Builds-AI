# Data and AI disclosure statement — Who Builds AI?

## Data
- Original source: Epoch AI, *Data on AI models*, https://epoch.ai/data/ai-models.
- Source file: `data/notable_ai_models.csv` (user-supplied fixed snapshot received 26 October 2026).
- Licence reported on Epoch AI's data page: Creative Commons Attribution (credit required).
- The raw file is redistributed without deliberate modification. Derived CSVs are regenerated by `analysis.py` and stored in `data/processed/`.
- Country data are attributed organisation labels, not individuals' citizenship; the sample is curated and does not include every AI model.
- The chosen window is 2010–2025. The 2026 calendar year is incomplete and excluded. Missing country information is excluded from the denominator.

## AI assistance
This project has used ChatGPT substantially for developing the research question, planning visualisations, writing and revising Python/Streamlit code, assisting calculations and tests, producing documentation, and drafting presentation materials. This work should **not** be represented as fully independent human authorship.

The testing described in the repository uses computational verification (mass conservation, a synthetic known-answer test, and a separate Python `csv` + `fractions.Fraction` recalculation of the 2025 headline). These checks may catch calculation errors but do **not** independently verify every source record or chart's visual readability. Browser/device and student-led checks remain to be performed before final submission.

The actual contributor(s), prompts and outcomes are recorded in `AI_PROVENANCE_MATRIX.csv`. Do not add fictional team members or claim a check passed without performing it. The assessed version will be identified by the final Git commit hash in the submission PDF.
