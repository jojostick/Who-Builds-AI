# Recording guide

## Before recording

- Confirm the group question, persona and your actual contribution with teammates. The supplied brief makes the group allocation final; this package cannot establish group agreement.
- Read the method and AI disclosure. Review the code and source data yourself.
- Launch the app. Use the default 2010–2025 range with the sensitivity checkbox off.
- On the verification tab select 2025. Check the displayed equation with a calculator: (311/3)/107*100.
- Inspect at least one single-country and one multi-country record. Check that repeated country labels are deduplicated.
- Rehearse aloud. Aim for 4:30 and finish before 5:00. The assessor stops at five minutes.
- Check microphone capture and text size. On Mac, Shift+Command+5 opens screen recording options; select a microphone before recording. Test a short clip and listen back.

## Eight-item recording checklist

- [ ] Recording is no longer than five minutes.
- [ ] Voice is audible and screen text is legible.
- [ ] The group's agreed question is stated.
- [ ] The persona is named.
- [ ] The presenter's actual contribution appears in the app or repository.
- [ ] A design decision is defended with a named alternative and reason.
- [ ] A displayed number is traced to original source data on screen.
- [ ] AI use and the check applied are disclosed accurately.
